## Prompt 1

build a mobile first (mobile friendly) slide deck for pune city sightseeing - pure HTML CSS JS only

make it look like a pune city sightseeing guide

web search is authorized for this project, you will need it a lot

user can flip through slides by swiping left or right - each slide on 1 page of its own

you need to number the sequence, and remember that in the future i may add more sights / slides in this deck in the beginning, so sequence may alter

Slides:
1. Intro
2. About Pune (500-year history)
3. Index (jump to any sight)
4+. One sight per slide — header (name), Google Maps link, top half (about/significance,
   what to notice, folklore/fun facts, scrollable), bottom half (photo)

## Decisions confirmed via clarifying questions
- Photos: download locally into /images (prefer Wikimedia Commons for stable, openly
  licensed images), not hotlinked.
- Maps: simple "Open in Google Maps" button linking to a maps search URL, no embedded
  iframe/API key.
- Index slide: numbered text list, tappable to jump to a sight slide.
